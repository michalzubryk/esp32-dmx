# Changelog / Historia zmian

## Public source package — 2026-11-25

English:
- Packaged firmware 1.1.0 with English and Polish documentation.
- Added desktop/mobile UI screenshots, wiring diagram, ArtDMX example and CI builds.
- Removed private station credentials; fresh public builds start with station mode disabled.
- Added Ethernet initialization compatibility for Arduino-ESP32 2.x and 3.x.
- Updated optional Docker tester target and non-overlapping fixture addresses.

Polski:
- Przygotowano firmware 1.1.0 z dokumentacja polska i angielska.
- Dodano zrzuty WWW, schemat, przyklad ArtDMX i kompilacje CI.
- Usunieto prywatne dane STA; nowe publiczne kompilacje maja STA wylaczone.
- Dodano zgodnosc Ethernetu z Arduino-ESP32 2.x i 3.x.
- Uaktualniono adres testera Docker i adresy bez nakladania kanalow.

## Firmware 1.1.0

English: dynamic direct channel profiles including laser10; NVS profile persistence; named pattern descriptions; editing and playback above CH8.

Polski: dynamiczne profile, laser10, zapis w NVS, opisy wzorow, edycja i odtwarzanie powyzej CH8.
